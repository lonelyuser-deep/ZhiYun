# 校遇 ZhiYun

一个面向在校学生的校园活动与机会信息网页原型。

## 已实现功能

- 活动信息首页：关键词、类型与信息来源筛选
- 信息详情：时间、地点、参与条件与更新提示
- 用户身份绑定：以本地昵称模拟微信身份绑定
- 收藏与感兴趣标记：数据保存在当前浏览器
- 学生信息发布：发布后直接进入信息流
- 信息状态提示：区分报名中、即将截止、待确认等状态

## 本地运行

直接在浏览器中打开 `index.html`，或在项目目录启动任意静态文件服务器后访问首页。

## 技术说明

项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖。用户身份、收藏、感兴趣标记和发布的信息通过浏览器 `localStorage` 保存。
